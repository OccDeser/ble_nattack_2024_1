\subsubsection{密钥熵迁移规则}

从攻击者的角度，爆破密钥的难度取决于该密钥所有的随机因素的遍历空间规模。

信息熵的可加性：如果子系统之间的相互作用是已知的，则可以通过子系统的熵来计算一个系统的熵。

根据信息熵的可加性，设计四种密钥的熵值：
\begin{itemize}
    \item 低熵（Low Entropy）：在可忽略的时间内，攻击者可以通过暴力破解获取的密钥的熵值。\\
            $1\;Low < 1\;Medium$
    \item 中熵（Medium Entropy）：在可接受的时间内，攻击者通过暴力破解获取的最长密钥的熵值。\\
            $1\;Low < 1\;Medium < 1\;High$
    \item 高熵（High Entropy）：在可接受的时间内，攻击者难以通过暴力破解获取的密钥的熵值。\\
            $2\;Medium <= 1\;High < 1\;Chaotic$
    \item 混沌熵（Chaotic Entropy）：在多项式时间内，攻击者永远无法通过暴力破解获取的密钥的熵值。\\
            $1\;High < 1\;Chaotic$
\end{itemize}

根据信息熵的可加性列举出以下规则，用于描述信息熵在密钥派生过程中的传递。

熵增：
\begin{itemize}
    \item Low + Low = Low
    \item Low + Medium = Medium
    \item Low + High = High
    \item Low + Chaotic = Chaotic
    \item Medium + Medium = High
    \item Medium + High = High
    \item Medium + Chaotic = Chaotic
    \item High + High = High
    \item High + Chaotic = Chaotic
\end{itemize}

熵减：
\begin{itemize}
    \item $<X, Y> - X = Y$
    \item $<X, Y> - Y = X$
\end{itemize}
